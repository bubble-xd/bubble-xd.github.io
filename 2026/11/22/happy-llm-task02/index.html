本篇是 Datawhale《Happy-LLM》的学习笔记，对应教材的第二章：Transformer 架构的 2.1 与 2.2 节。学完第一章的词向量和 ELMo 之后，这一部分主要解决三个问题：为什么 Transformer 要用注意力机制替代 RNN；缩放点积注意力和多头注意力在张量维度上具体怎么算、Mask 放在哪一步；以及 Encoder–Decoder 里自注意力和交叉注意力的数据流是如何配合的。

2.1 注意力机制

为什么用注意力替代 RNN

在 Transformer 之前，处理序列文本主要靠 RNN 和 LSTM。这类结构存在两个瓶颈：

  • 无法在时间步上并行：隐藏状态必须按 顺序递推，限制了 GPU 的并行计算能力，长序列训练耗时很高。
  • 长距离依赖衰减：距离较远的两个 token 需要经过多步隐藏状态传递才能建立联系，序列越长越容易丢失早期信息。

注意力机制直接计算序列中任意两个位置的关联度，把任意两个 token 之间的交互路径降到 ，同时允许整个序列以矩阵乘法一次性并行计算。

Q、K、V 的来源与维度

注意力机制包含三个变量：Query（查询）、Key（键） 和 Value（值）。可以按软匹配字典来理解：Key 决定某个位置对外暴露什么检索特征，Value 存放该位置要被聚合的内容，Query 拿着当前需求去和所有 Key 算相似度，再按归一化后的权重对 Value 加权求和。

代码实现中不会真的建 组独立的线性层循环计算，而是直接用三个合并的投影矩阵 wq、wk、wv 一次算完，再拆分维度并交换轴，把 n_heads 放到批次维之后：

  1. 线性投影：(B, T, n_embd) (B, T, dim)，其中 dim = n_heads * head_dim。
  2. 拆头并转置：view(B, T, n_heads, head_dim).transpose(1, 2) (B, n_heads, T, head_dim)，使 torch.matmul 直接在最后两维 (T, head_dim) 上对所有样本和所有头并行做注意力。
  3. 合并与输出投影：output.transpose(1, 2).contiguous().view(B, T, dim) 经 self.wo 映射回残差流。这里必须调用 .contiguous()，因为 transpose 只改变步幅（stride）而不重新排列底层内存，直接 view 会报错。

2.2 Encoder–Decoder

Seq2Seq 与整体数据流

Transformer 最初用于机器翻译等 Seq2Seq 任务：输入源序列 ，输出可能不等长的目标序列 。模型拆成两段，Encoder 负责把源序列编码成包含上下文信息的隐藏表示，Decoder 负责结合已生成的目标前缀和 Encoder 输出逐步解码出后续 token。

内部基础组件

EncoderLayer 和 DecoderLayer 除了注意力层外，还共用三种基础结构：

  • 前馈神经网络（FFN / MLP）：由两层线性变换和中间的 ReLU 激活构成（Dropout(W2(ReLU(W1(x))))），在每个 token 位置上独立执行。注意力负责在序列各个位置之间搬运和混合信息，FFN 则负责在单个位置的通道维度内部做非线性特征变换。
  • 层归一化（Layer Norm）：为了缓解深层网络内部激活值分布漂移的问题，Transformer 选用 Layer Norm 而不是图像任务常用的 Batch Norm。Batch Norm 在 batch 维度统计均值和方差，受限于 batch size 大小，也无法直接处理变长序列中不同时间步的分布差异；Layer Norm 直接对单个样本在特征维度（dim=-1）上做归一化，与 batch 大小和序列长度无关。

  • 残差连接与 Pre-Norm：每个子层外部都包一层跳跃连接，允许底层梯度和原始表示直接传向高层。教材图 2.5 画的是原论文示意图里的 Post-Norm（LayerNorm(x + Sublayer(x))），而教材 2.2 节代码实际写的是现代大模型常用的 Pre-Norm：

采用 Pre-Norm 时，残差主干上没有归一化层阻挡梯度，训练更稳定；但最后一层输出可能未经归一化，因此在 Encoder 和 Decoder 堆叠的末尾都会额外补一个 self.norm。

Encoder 与 Decoder 的结构对比

原论文中 Encoder 和 Decoder 各堆叠 层，单层内部的注意力安排对比如下：

模块 包含子层 掩码设置 K、V 来源 作用
EncoderLayer 双向自注意力 FFN is_causal=False 均来自本层输入 每个源 token 都能汇总整句上下文，生成编码表示 enc_out
DecoderLayer（子层 1） 掩码自注意力 is_causal=True 来自 Decoder 输入 限制目标序列只能聚合当前及历史位置，防止训练时偷看未来词
DecoderLayer（子层 2） 交叉注意力 FFN is_causal=False 来自 Encoder 输出 enc_out 以解码端状态为 Query 检索编码端全句信息，建立源与目标的对齐

在 DecoderLayer.forward(x, enc_out) 中，交叉注意力传入的是 (norm_x, enc_out, enc_out)，此时不加因果掩码，因为整个源序列对目标序列的任意生成位置都是已知且应当可见的。
