Happy-LLM Task01 学习笔记：NLP 基础概念

发表于2026-11-18|更新于2026-11-19|LLMHappy-LLM
|总字数:1.7k|阅读时长:5分钟|浏览量:

本篇是 Datawhale《Happy-LLM》的学习笔记，对应教材的第一章：NLP 基础概念。

这是我第二遍读 Happy-LLM 第一章。这次主要想弄清楚，开始学 Transformer、BERT 和 GPT 之前，需要先理解哪些 NLP 概念。我先记下三个问题：文本按什么单位切分，这些单位怎么用向量表示，以及语言模型怎么根据上下文预测后续内容。

NLP 是自然语言处理，研究怎么让计算机理解和生成人类语言。第一章主要讲 NLP 的发展、常见任务和文本表示。

发展历程

  • 规则方法（20 世纪 40 至 60 年代）：早期机器翻译依赖人工编写的词典和语法规则。遇到歧义或复杂句式，就需要补充规则。
  • 统计方法（20 世纪 70 至 90 年代）：有了更多语料之后，可以从数据里统计哪些词经常一起出现，再用概率做分词、词性标注或翻译。
  • 深度学习方法（21 世纪以来）：用神经网络从语料中学习特征和语言表示。第一章讲到的 Word2Vec 和 ELMo 就是两个例子。Word2Vec 学到的是固定的词向量，ELMo 还会根据句子的上下文改变词向量。

我理解这段变化主要看一件事：处理语言时所用的规律，有多少需要人写出来，有多少能从语料中学到。

九个任务

教材列了中文分词、子词切分、词性标注、文本分类、实体识别、关系抽取、文本摘要、自动问答和机器翻译。先拿三个任务看它们各自的输入和输出：

任务 输入 输出
中文分词 今天天气真好，适合出去游玩 今天 / 天气 / 真 / 好 / ， / 适合 / 出去 / 游玩 / 。
实体识别 李彦宏是北京市海淀区的居民 李彦宏 → 人名；北京市海淀区 → 地名
机器翻译 今天天气很好。 The weather is very nice today.

中文分词主要是确定词的边界。比如「雍和宫的荷花开得很好」，应该保留「雍和宫」这个地名。如果切成「雍和 / 宫 / 的荷」，下游做实体识别时就更难识别出完整的地名。

子词切分考虑的是词表怎么覆盖更多输入。比如 unhappiness 可以拆成 un + happi + ness。即使词表里没有整个单词，也可以用已有的子词表示它。这个例子让我分清了两者的目标：中文分词希望找出有语言意义的词，子词切分可以使用比词更小的单位。BPE、WordPiece 和 Unigram 选择子词的方式各不相同，SentencePiece 支持 BPE 和 Unigram 等方法。

剩下几个任务也可以按输出区分：

  • 词性标注：给每个词标注词性，比如 She/PRP、is/VBZ、playing/VBG。
  • 文本分类：给一段文本分配类别，比如把 NBA 赛程新闻归到体育类。
  • 关系抽取：从句子中抽取实体之间的关系。比如从「比尔·盖茨是微软公司的创始人」得到「比尔·盖茨、创始人、微软公司」。
  • 自动问答：根据问题返回答案。可以从文档检索，也可以查询知识库。
  • 文本摘要：抽取式摘要从原文挑选关键句，生成式摘要可以重新组织语言。教材的天问一号例子把一段报道压缩成了一句话，保留了着陆结果和任务的意义。

文本表示

这一节我主要看两件事：向量怎么得到，以及同一个词在不同句子里会不会有不同的表示。

  • 向量空间模型（VSM）：用词表作为向量的维度。比如用二值向量表示一句话，出现的词取 1，其余取 0。词表大小是 16384，句子只包含 5 个不同的词时，就只有 5 个位置为 1。这种表示很稀疏，也很难直接体现「猫」和「狗」的语义联系。
  • N-gram 语言模型：根据前面有限的几个词估计当前词出现的概率。比如用 trigram 计算 The quick brown fox，预测 brown 时看 The quick，预测 fox 时看 quick brown。N 越大，需要统计的组合越多。未经平滑时，语料中没出现过的组合还会得到零概率。
  • Word2Vec：用预测任务学习稠密词向量。CBOW 用周围的词预测中心词，Skip-gram 用中心词预测周围的词。我之前只记住两者方向相反。这次注意到它们都在用局部上下文学习词之间的关系。训练完成后，同一个词通常查到的是同一个向量。
  • ELMo：先预训练双向语言模型，再用双向 LSTM 的各层输出构造词表示。因为表示依赖句子上下文，同一个词在不同句子中可以得到不同的向量。

N-gram 和 Word2Vec 都会用到上下文。我记它们的区别时主要看输出：N-gram 要估计某个词出现的概率，Word2Vec 要学到可以复用的词向量。

分词、词表示和语言模型的关系

还是用「雍和宫的荷花很好看」举例：

  1. 分词确定模型处理的单位，比如「雍和宫 / 的 / 荷花 / 很 / 好看」。
  2. 词表示把这些单位表示成向量，比如 one-hot 表示或训练得到的稠密向量。
  3. 语言模型根据上下文给后续单位分配概率。比如输入「雍和宫的荷花很」，模型会估计以「好看」等候选词续写的概率。

如果改变切分方式，模型接收到的单位也会变。后面看 GPT 时，可以用这个例子区分 tokenizer 的输出、模型的输入，以及模型实际在预测什么。

疑问与验证

ELMo 在下游任务里算微调还是特征提取？

教材一处提到「微调得到适合任务的词向量」，另一处写的是「提取词向量作为新特征」。我理解这里要看预训练模型的参数有没有更新。ELMo 的典型用法是冻结预训练语言模型，取出不同层的表示，再为下游任务学习这些表示的组合权重。这种用法属于特征提取。BERT 常见的做法是把预训练模型和下游任务的参数一起微调。

有了子词切分，还需要单独做中文分词吗？

要看具体任务。如果用的是采用 BPE 等方法的语言模型，一般直接用模型自带的 tokenizer。如果任务需要明确的词边界，比如按词检索或使用词级规则，中文分词仍然有用。
